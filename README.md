# Altoro Mutual Penetration Test Report

This repository contains a black-box web application penetration testing report for the Altoro Mutual demo banking application.

The report was created for learning and portfolio purposes to demonstrate practical web application security testing, vulnerability documentation, proof-of-concept writing, impact analysis, and remediation recommendations.

---

## Scope

- Target: Altoro Mutual demo web application
- Testing Type: Black-box penetration testing
- Focus: Web application security assessment
- Methodology: Manual testing supported by security tools

---

## Report Summary

The report documents 21 security findings with severity classification, proof-of-concept screenshots, impact explanation, and recommended remediation steps.

### Findings Covered

- SQL Injection
- Blind SQL Injection
- SQL Injection Login Bypass
- Reflected Cross-Site Scripting (XSS)
- Stored Cross-Site Scripting (Stored XSS)
- Insecure Direct Object Reference (IDOR)
- Broken Authorization
- Broken Authentication
- Cross-Site Request Forgery (CSRF)
- Session Hijacking
- Open Redirect
- HTML Injection
- Missing Login Rate Limiting
- Information Disclosure
- Security Misconfiguration
